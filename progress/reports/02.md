## 实际完成

- `migrations/0001_persistence.sql` 建立租户、项目、用户、价格版本/价格项、请求、尝试、计费账户、结算、不可变 journal 表及复合租户外键。
- 价格模型包含 `price_items.dimension`、精确 `NUMERIC(30,12) unit_price`、发布版本至少一条价格项的延迟约束、结算 `currency` 与 `price_snapshot`，并通过复合外键固定租户币种。
- journal entries 包含 currency 复合外键；延迟约束触发器要求每个 journal transaction 至少两笔、同币种且金额和为零；journal 与已发布价格行不可 UPDATE/DELETE。
- `internal/storage/migrate` 使用 advisory lock、版本顺序、历史连续前缀校验、migration name/checksum 漂移拒绝、未来版本拒绝和短事务；重复执行幂等；启动兼容检查同样验证完整历史名称/checksum/连续性。
- 迁移 SQL 作为二进制内置资源，`migrate` 与带 database 配置的 `serve` 不依赖 CWD；`make generate-check` 校验根 SQL 与内置 SQL 一致。
- `ReadDatabaseDSN` 通过 no-follow fd 读取并 fstat 同一句柄，拒绝 symlink、目录/特殊文件、非当前用户拥有、group/other 权限文件及空内容；错误不回显秘密。
- 应用角色集成夹具仅授予全表 SELECT 与 requests/request_attempts 的 INSERT/UPDATE；撤销 TEMP、DDL、租户/项目/用户/价格/账本/结算/迁移历史写权限；测试覆盖已发布价格项 UPDATE/DELETE、非零/混币种账本、危险写操作、serve/migrate schema compatibility、历史 checksum 漂移。
- 集成 DSN 门禁要求显式 loopback TCP 目标并拒绝 host/hostaddr/service/socket 路由覆盖；不读取默认或生产数据库。
