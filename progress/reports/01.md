# 阶段 01 · 领域类型、接口与配置契约

状态：implemented（等待 `prompts/REVIEW.md` 独立复核）

## 已实现

- `internal/domain` 提供 UUIDv7、UTC 时间、租户/项目/主体/请求/尝试/凭据的区分类型，Money 微单位解析与溢出/币种校验，单调状态转移、Usage known/unknown 计数、CredentialVersion、能力与权限 scope、安全错误。
- `internal/config` 提供严格强类型 YAML：未知字段、重复键、别名、多文档、超大输入和未知 `URBINO_` 变量拒绝；配置路径遵循 `--config` > `URBINO_CONFIG` > 工作目录 `urbino.yaml`；生产环境拒绝测试模式、公网管理、明文数据库/Valkey URL、关闭 TLS 和空 provider allowlist。
- `api/admin.openapi.yaml` 与 `api/admin_types.gen.go` 固定管理契约和 `Urbino` 标题；公共流式协议不使用管理 JSON writer。
- `internal/protocol` 提供有界严格 JSON、重复键/深度/UTF-8/尾随校验、逐 endpoint allowed/forbidden/bounded-pass-through 策略；`internal/provider` 提供最小适配端口。所有公共能力默认 disabled，未认证与未启用能力分别返回稳定错误。
- 新增配置 JSON Schema、开发/生产样例和公共字段策略文档；未创建数据库、provider listener、真实上游调用或假成功管理 handler。
