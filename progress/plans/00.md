# 阶段 00 实施计划

状态：in_progress

## 目标
- 建立可编译 Go module `example.com/urbino`，入口 `cmd/urbino`。
- 实现 `urbino version`、`urbino serve` 最小命令、配置路径选择与内部 health listener。
- 锁定实际 Go 与直接依赖版本，补齐 Makefile、基础 CI、忽略文件、ADR、依赖记录。
- 为 P00-T01..P00-T04 建立真实验证与证据。

## 非目标
- 不实现真实模型调用、租户/鉴权/账务/数据库/Valkey、管理 API 或部署。
- 不调用真实上游，不修改全局 OMP 配置，不提交或部署。

## 不变量
- 正式名称仅为 Urbino；默认 module 仍为 `example.com/urbino`，除非发现已确认正式路径。
- 健康接口仅内部 listener，默认不暴露管理或推理路径。
- 配置秘密不进示例、日志、命令行或测试输出；未知命令非零退出。
- 不引入 CPA/S2A module、SDK、子模块或实现代码。

## 公共契约
- CLI：`urbino version` 可读并成功；未知命令非零；`urbino serve` 读取 `--config` > `URBINO_CONFIG` > `./urbino.yaml`，缺失文件明确失败。
- 环境：应用配置前缀 `URBINO_`，配置路径变量 `URBINO_CONFIG`。
- Go 入口：`cmd/urbino`；内部包按 `docs/01-architecture.md` 逐阶段创建。

## 文件所有权
- implementer：仅初始 `cmd/urbino`、配置/health 运行时代码及其必要单测。
- tester：仅阶段测试/证据目录，不改生产契约。
- 主 Agent：go.mod/go.sum、Makefile、CI、依赖/ADR/忽略文件、总状态与阶段证据。

## 必要命令
- `gofmt -w`（受影响 Go 文件）
- `go test ./...`
- `go vet ./...`
- `go build ./cmd/urbino`
- `go list -m all` 并确认无 CPA/S2A module
- `make fmt`, `make vet`, `make test`, `make build`（若已建立）

## 验收
- P00-T01：test/vet/build 真实成功。
- P00-T02：依赖可解析、go.sum 存在、无 CPA/S2A module。
- P00-T03：示例/日志/默认配置无实际 key 或默认管理员口令。
- P00-T04：version、未知命令、内部 health 与无裸露推理接口行为有实测证据。
- 完成本阶段后状态只能写 `implemented` 或 `blocked`，不写 `verified`；随后停止进入独立 review。
