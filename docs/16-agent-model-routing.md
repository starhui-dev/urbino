# 16 · Agent 运行时适配与能力核验

本项目不绑定具体 Agent CLI、模型供应商、登录方式或全局配置。Agent 文件只描述角色职责和边界，运行时由操作者选择并按实际能力适配。

## 接入前核验

1. 记录当前 Agent 运行时能提供的版本、帮助或能力清单；没有对应接口时记录 `not_available`，不猜测版本。
2. 只读取配置来源的非敏感元数据。不要原样输出配置、模型清单、认证文件或环境变量值；不要自动登录、升级、安装插件或修改全局设置。
3. 核验当前会话、模型、工具、工作区隔离、并发和任务终态语义。显示名称不能证明底层模型身份，文件存在不能证明资源已加载。
4. 为项目角色绑定运行时实际支持的模型或角色选择器；无法确认时保持空值并阻塞需要该能力的任务。不要把 Sol、DS、GLM Flash、Luna 等偏好名称当作模型 ID。
5. 用小范围只读、写入、测试和独立复核 smoke 验证工具边界。不得调用 Urbino 真实上游、生产凭据或外部压测。
6. 把脱敏版本、能力摘要、角色解析、任务终态、配置指纹和证据路径写入 `evidence/agent/runtime.json`；未实测项保持 `not_run`。

## 角色映射

| 角色 | 职责 | 最低要求 |
|---|---|---|
| 主 Agent | 规划、架构、整合、验收 | 能读取仓库、维护状态并运行批准的检查 |
| urbino-scout | 只读定位代码和约束 | 只读工具；不写文件、不运行命令 |
| urbino-implementer | 实现明确的小切片 | 仅任务范围内的写入和本地命令 |
| urbino-tester | 编写或执行边界测试 | 仅任务范围内的测试与证据写入 |
| urbino-reviewer | 独立只读复核 | 新上下文；不修改、不把观察当作亲自执行 |
| urbino-security | 安全、凭据、账本专项复核 | 只读；不接触真实秘密或生产数据 |

## 配置保护

`.agents/agent-policy.json` 只描述本项目的任务边界，不是任何运行时的配置文件。不要把它复制到全局配置目录，也不要写入 API Key、Token、Base URL 密钥或模型凭据。运行时不支持某个 frontmatter 字段时，删除该字段并保留文字约束，不能自造兼容字段。

通用 Agent 没有统一的任务 JSON、隔离、热加载或模型路由协议。具体字段以当前运行时公开能力为准；未知字段、未知权限和无法取得的终态都按阻塞处理。旧运行证据不能直接复用，配置或角色变化后必须重新验证。
