# 通用 Agent 提示词设计依据

本项目的提示词、角色和技能只依赖 Markdown、JSON 与仓库内的离线校验脚本，不依赖特定 Agent CLI、插件、登录方式或全局配置。目录结构和 frontmatter 是本项目约定；实际 Agent 运行时可按自身能力映射，不能把文件存在当作已加载或已验证。

## 设计原则

- 根目录 `AGENTS.md` 负责项目边界；`.agents/agents/` 保存角色提示词；`.agents/prompts/` 保存阶段入口；`.agents/skills/` 保存按需技能。
- 每个角色声明名称、职责、工具边界和结构化输出。只读角色不得写文件；实现和测试角色只能写任务单明确的路径。
- 任务合同明确目标、非目标、输入、输出、文件所有权、测试命令、证据路径和停止条件。主 Agent 独占阶段状态与最终证据。
- 通用 Agent 运行时没有统一的模型 ID、任务 JSON、隔离语义或热加载保证。模型、工具、并发和工作区能力必须在实际会话中核验；未知能力按阻塞处理。
- 提示词不会提供权限沙箱、秘密隔离、网络策略、审批或部署能力。安全边界仍由运行环境和仓库规则共同决定。

具体工作流见 [Agent 工作流](../docs/15-agent-workflow.md)、[运行时适配](../docs/16-agent-model-routing.md) 和 [迁移恢复](../docs/17-agent-migration-recovery.md)。这些文档描述项目约束，不代表任何特定工具的兼容性认证。
