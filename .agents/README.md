# Urbino 的通用 Agent 入口

`prompts/` 提供十个 `urbino-*` 阶段入口；`agents/` 提供五种具明确工具边界的角色；`skills/urbino-development/SKILL.md` 提供按需开发指引。

本目录没有全局配置、密钥、可执行扩展、SYSTEM.md 或自动审批设置。模型和工具能力由接入时的实际 Agent 运行时核验；发行提示词不硬编码模型。更新已有目录必须合并，不能覆盖用户原有配置。

从仓库根目录读取这些文件并交给当前 Agent 会话执行。资源未出现时先确认 `.agents/` 已复制、当前工作目录正确并记录阻塞；不要宣称文件存在就代表成功加载。
