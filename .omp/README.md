# Urbino 的项目级 OMP 入口

prompts/ 提供十个 /urbino-* 模板；agents/ 提供五种具明确工具边界的角色；skills/urbino-development/SKILL.md 提供按需开发指引。

本目录没有全局配置、密钥、可执行扩展、SYSTEM.md 或自动审批设置。Agent 的真实模型绑定在首次 /urbino-setup 由当前环境核验后最小化写入；发行模板不硬编码模型。更新已有目录必须合并，不能覆盖用户原有配置。

从仓库根目录启动 OMP。模板未出现先确认 .omp 隐藏目录已复制、当前工作目录正确、版本发现机制与同名冲突；按当前版本帮助刷新或重新进入。不要宣称文件存在就代表成功加载。
